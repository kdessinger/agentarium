## Product implications

For Agentarium, this suggests a stronger architecture metaphor:

1. **Spatial HQ / space station / dungeon** — rooms are capabilities.
2. **Rooms as operational modules** — factory, research, armory, blueprint center, etc.
3. **Visual business pipelines** — conveyor belts / queues / flows map to real work.
4. **Access control terminal** — one place to inspect connected accounts, API keys, permissions, and tool access.
5. **Skill armory** — manage agent skills like equipment, with provenance and safety status.
6. **Skill quarantine/replication workflow** — never install unknown skills directly; inspect and reproduce safe behavior.
7. **Always-visible risk model** — third-party tools/skills need trust boundaries.

## Safety/design note

The “download, inspect, replicate” idea is worth preserving. For Agentarium, imported skills should have statuses such as:

- discovered
- downloaded to quarantine
- inspected
- replicated
- approved
- installed/enabled
- rejected

Direct install from a marketplace should be discouraged or gated.
