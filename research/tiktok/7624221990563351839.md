## Etsy / Forge workflow

```text
Nova / Research Agent
  → researches Etsy products and stores performing well
  → extracts inspiration/opportunities
  → sends research to Forge

Forge / Factory Agent
  → receives Nova's research
  → uses Nano Banana Pro / Gemini to design products
  → uses Printify product templates
  → connects through Printify API key
  → connects through Etsy API key
  → creates products/listings for Etsy
  → creates product photos from templates
  → sends product photos to Pixel

Pixel / Media Agent
  → curates product photos into TikTok slideshows
  → posts/distributes marketing content
  → also supports YouTube/media work

Printify
  → receives designs on templates
  → prints/manufactures products after Etsy orders
  → ships products to customers

Etsy
  → storefront/order channel
  → receives products/listings
  → sends order demand into fulfillment flow
```

## Training / feedback system

This is the most important new concept in the video.

When Forge first started designing, AndrooAGI says the designs were poor. He built an approve/reject feedback system:

```text
Forge shows candidate design
  → human approves or rejects
  → feedback is stored
  → repeated hundreds of times over 2–3 days
  → Forge becomes trusted enough to create products autonomously
```

Product implication:

Agentarium needs a **Training / Feedback Loop** or **Approval Trainer** for each lab. New labs should start in supervised mode, learn from approve/reject feedback, and only later graduate to higher autonomy.

Candidate lab maturity states:

- draft
- supervised
- training
- trusted
- autonomous-with-audit
- suspended

## Product implications for Agentarium

1. The spatial canvas must support **conveyor belts as real business pipelines**.
2. Labs need dashboards that expose revenue, orders, current work, connected accounts, and fulfillment state.
3. Research-to-production handoff is central: Nova → Forge.
4. Production-to-marketing handoff is central: Forge → Pixel.
5. Platform integrations should be visible as tools inside labs, not hidden settings.
6. Factory labs need staged approval/training before autonomy.
7. Approval/reject feedback is not just governance; it is a training mechanism.
8. Agentarium should track lab trust/maturity state before allowing autonomous publishing.

## Safety implications

- API keys for Etsy/Printify must be permission-scoped and vault-backed.
- Publishing products/listings is an external commercial action and should be gated until the lab is trusted.
- Fulfillment/shipping flows affect real customers and money; they need audit logs.
- Agent-generated product designs should pass quality/IP/policy checks before publication.
