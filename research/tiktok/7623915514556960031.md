## Station / agent map

### Command chair / master dashboard

Occupant: AndrooAGI / human operator

Purpose:

- manage the entire ship/system from one dashboard
- see Etsy store revenue
- see what each agent is doing
- see weekly performance
- manage the overall operation

Product implication for Agentarium:

Agentarium needs a **Mission Control / Command Deck** that gives the human one place to view overall revenue, lab activity, agent status, performance, alerts, and pending approvals.

### Ultron — main commander

Location: same command room as the human operator

Model mentioned: Opus 4.6

Purpose:

- main commander of the entire ship
- keeps the operation running when the human is absent
- high-capability orchestrator / steward agent

Product implication:

Agentarium needs a top-level **orchestrator/steward agent** distinct from specialized lab agents. This agent monitors the whole system, delegates work, and maintains continuity.

### Nova — research lab

Location: research lab

Purpose:

- constantly researches businesses being run
- especially researches automated businesses in the factory rooms
- researches Etsy products performing well
- researches competing stores
- takes research over to Forge

Product implication:

Agentarium needs a **Research / Market Intelligence Lab** that produces structured opportunity packets for downstream labs.

### Forge — factory / Etsy store lab

Location: factory room

Purpose:

- focuses solely on the Etsy store
- receives research from Nova
- makes Etsy listings
- connected to Nano Banana Pro for design
- connected to Printify
- Printify connects to Etsy to manufacture/ship products

Product implication:

Agentarium needs **Factory Labs** that turn research into products/listings and connect to fulfillment/publishing platforms. Tool connections and external writes must be visible and gated.

### Pixel — design / Fiverr thumbnail lab

Location: design/Fiverr area

Purpose:

- main designer of the station itself
- designed space / each room
- connected to Nano Banana Pro
- creates YouTube thumbnails for Fiverr customers
- runs the Fiverr service

Product implication:

Agentarium needs a **Design / Creative Production Lab** that can handle customer-order work and internal UI/world design. Pixel also proves agents can operate both on the system and inside the system.

### Cipher — communications deck

Location: communications deck

Purpose:

- manages emails
- responds to emails
- monitors TikTok/video comments
- picks up comments and reports them to the human

Product implication:

Agentarium needs a **Communications Deck** responsible for inbound/outbound messages, email, comments, support channels, alerts, and human notification routing.

## Orchestration layer pattern

The implied orchestration layer is:

```text
Human command deck
  ↔ Ultron / steward orchestrator
      ↔ Nova / research lab
          → Forge / factory lab
              → Nano Banana Pro / design tool
              → Printify / fulfillment
              → Etsy / storefront
      ↔ Pixel / design + Fiverr service lab
          → Nano Banana Pro
          → Fiverr customer work
      ↔ Cipher / communications deck
          → email
          → comments/social signals
          → human alerts
```

## Product lessons

1. The map needs to show **where each agent is** and **what each agent is doing**.
2. The command deck needs global business metrics and per-agent status.
3. The steward/orchestrator should be visible as a real entity, not hidden backend logic.
4. Research should feed downstream production labs.
5. Factory/production labs should expose their connected platforms and toolchains.
6. Creative/design agents can both produce customer work and improve the visual system itself.
7. Communications needs its own station; inbound signals are work triggers.
8. Every lab should show current work, last output, connected tools, and handoff targets.
9. Agentarium should model agent-to-agent handoffs as visible routes between stations.
