# Legacy Phase 2 Prototype

The first Phase 2 frontend was preserved locally at:

```text
/root/Kenn/projects/agentarium/legacy/phase2-first-pass
```

It is not active source and is ignored by Git. Its deterministic synthetic fixture flow is classified as legacy Demo-only.

The active `app/` path was intentionally cleared for a clean Phase 2 rebuild based on the current requirements:

- self-building first-run commissioning
- independent visual-style and world-template selection
- Pixel Art optional for every theme
- ten world templates including Modern Corporate Office
- image-first World Overview → Room View → Agent View
- Standard mode as the default with zero synthetic operational data
- optional isolated Demo mode
- provenance, adapter boundaries, approvals, event audit, and replay

The legacy directory exists only for visual or code-reference comparison. Do not copy its fixture-first state architecture into Standard mode.
